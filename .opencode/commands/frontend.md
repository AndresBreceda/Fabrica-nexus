Levanta el frontend de Fabrica-nexus.

1. Verifica que el directorio `frontend/` exista.
2. Verifica que `frontend/package.json` exista.
3. Si las dependencias no están instaladas, ejecuta `npm install` dentro de `frontend/`.
4. Ejecuta `npm run dev` dentro de `frontend/`.
5. No modifiques archivos del proyecto.
6. Al iniciar el servidor, indícame la URL local disponible.

El comando debe ejecutarse desde la raíz del repositorio.
